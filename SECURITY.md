# Security

## Scope

Security issues include unsafe parsing, memory/bounds defects, unsafe package or file publication, signature/verification mistakes, privilege-boundary errors, unsafe diagnostic transmit behaviour and any path where untrusted input can cause unintended code, data or device modification.

## Reporting

Do not publish sensitive exploit details publicly. Use GitHub private vulnerability reporting/security advisories when available.

Include the affected revision, environment, reproduction, expected/observed behaviour and impact boundary.

## Response

Treat security issues as correctness defects: reproduce, test, fix the underlying contract and validate the affected boundary.

## Supported source

Current main and the current release line are the primary maintained sources unless documented otherwise.

# Documentation

Package Repository uses the same canonical documentation structure as the rest of the Infiltrator project family.

- [Architecture](ARCHITECTURE.md) — publication components, data flow and ownership.
- [Design](DESIGN.md) — first-principles repository philosophy and failure model.
- [Decisions](DECISIONS.md) — durable architectural choices.
- [Roadmap](ROADMAP.md) — current foundation and direction.
- [Validation](VALIDATION.md) — package, signing and lifecycle evidence.
- [Project README](../README.md) — user/operator overview.
- [Changelog](../CHANGELOG.md) — contract-relevant history.
- [Contributing](../CONTRIBUTING.md) — development rules.
- [Security](../SECURITY.md) — vulnerability reporting.

The C++ repository tool and tests define executable publication behaviour. These documents define ownership, rationale, direction and evidence without duplicating generated repository state.
